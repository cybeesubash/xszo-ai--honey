Step 1: Build Dashboard
  • cd dashboard
  • npm install --legacy-peer-deps
  • npm run build
  • Creates: dashboard/dist/ with HTML/CSS/JS

Step 2: Install Backend
  • cd ../backend
  • pip install -r requirements.txt

Step 3: Start Backend
  • cd backend
  • Backend starts and detects dashboard/dist/
  • Serves dashboard at / (root)
  • Serves API at /api/*, /logs, /stats, etc.

┌──────────────────────────────────────────────────────────────────┐

URL Routing:
  GET /               → Dashboard (index.html)
  GET /assets/*       → Dashboard CSS/JS files
  GET /health         → API Health Check
  GET /docs           → API Documentation
  GET /logs           → API Endpoint
  GET /stats          → API Endpoint
  POST /api/event     → API Endpoint
  WebSocket /ws/live  → Real-time updates

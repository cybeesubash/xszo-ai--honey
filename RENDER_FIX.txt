PROBLEM: Build changes directory, Start command can't find backend

SOLUTION: Use absolute paths with $PWD or go back to root

┌──────────────────────────────────────────────────────────────────┐
│ ✅ FIXED START COMMAND (Use This)                                │
└──────────────────────────────────────────────────────────────────┘

Option 1 (Recommended):
────────────────────────────────────────────────────────────────────
python -m uvicorn backend.main:app --host 0.0.0.0 --port $PORT
────────────────────────────────────────────────────────────────────

Option 2 (Alternative):
────────────────────────────────────────────────────────────────────
cd backend && python -m uvicorn main:app --host 0.0.0.0 --port $PORT || (cd ../backend && python -m uvicorn main:app --host 0.0.0.0 --port $PORT)
────────────────────────────────────────────────────────────────────

Option 3 (Most Reliable):
────────────────────────────────────────────────────────────────────
bash -c "cd backend && python -m uvicorn main:app --host 0.0.0.0 --port \$PORT"
────────────────────────────────────────────────────────────────────

┌──────────────────────────────────────────────────────────────────┐
│ 🎯 RECOMMENDED: Option 1 (Simplest)                              │
└──────────────────────────────────────────────────────────────────┘

Build Command (Keep Same):
cd dashboard && npm install && npm run build && cd ../backend && pip install -r requirements.txt

Start Command (USE THIS):
python -m uvicorn backend.main:app --host 0.0.0.0 --port $PORT

This works because:
• Python can import backend.main from root directory
• No cd needed - stays in root
• Simple and reliable

┌──────────────────────────────────────────────────────────────────┐
│ 🔧 HOW TO UPDATE ON RENDER                                       │
└──────────────────────────────────────────────────────────────────┘

1. Go to your service in Render dashboard
2. Click "Settings" (left sidebar)
3. Scroll to "Build & Deploy"
4. Find "Start Command"
5. Replace with:
   python -m uvicorn backend.main:app --host 0.0.0.0 --port $PORT
6. Click "Save Changes"
7. Manually trigger "Deploy" from dashboard

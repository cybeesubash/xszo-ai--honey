═══════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

If HoneyBot_Setup is still visible after 30 seconds:
→ WiFi password might be wrong
→ Press ESP32 RESET button (small button on board)
→ Try configuration again with correct password

If ESP32 RESET button doesn't work:
→ Unplug USB cable
→ Wait 5 seconds
→ Plug back USB cable
→ Wait for HoneyBot_Setup to appear
→ Try configuration again

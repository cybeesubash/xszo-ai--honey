└──────────────────────────────────────────────────────────────────┘

Branch: main

Build Command:
────────────────────────────────────────────────────────────────

────────────────────────────────────────────────────────────────

STEP 1: DEPLOY BACKEND
═══════════════════════
1. Go to https://dashboard.render.com

3. Connect GitHub: cybeesubash/xszo-ai--honey

7. ✅ Copy Backend URL: https://cyber-eye-backend.onrender.com

STEP 2: DEPLOY DASHBOARD
═════════════════════════
1. Click "New +" → "Web Service" again
2. Connect same GitHub repo
3. Fill in Dashboard details above
4. ⚠️ IMPORTANT: Replace backend URL in env vars with YOUR actual URL!
5. Click "Create Web Service"
6. Wait 5-8 minutes for build
7. ✅ Dashboard URL: https://cyber-eye-dashboard.onrender.com

┌──────────────────────────────────────────────────────────────────┐
│ 🔧 STEP 3: UPDATE BACKEND CORS (IMPORTANT!)                      │
└──────────────────────────────────────────────────────────────────┘

After both services are live, update backend CORS:

1. Go to Backend service → Environment
2. Add new variable:
   CORS_ORIGINS=https://cyber-eye-dashboard.onrender.com,http://localhost:5173
3. Save and redeploy backend

┌──────────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                               │
└──────────────────────────────────────────────────────────────────┘

Dashboard shows "Network Error":
→ Check VITE_API_URL matches your backend URL exactly
→ Update CORS_ORIGINS in backend with dashboard URL
→ Redeploy both services

Backend not starting:
→ Check environment variables are set
→ View logs in Render dashboard
→ Verify requirements.txt exists in backend/

Dashboard not building:
→ Use --legacy-peer-deps flag in build command
→ Check package.json exists in dashboard/
→ Clear build cache and redeploy
